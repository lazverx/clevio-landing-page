# Clevio AI Staff — Landing Page

Official landing page for **Clevio AI Staff** (operated by PT Clevio). A modern, interactive web application featuring live WhatsApp AI staff simulation, multi-industry solutions, responsive mobile-first architecture, and bilingual (ID/EN) support.

Live URL: [https://chiefaiofficer-alpha.vercel.app](https://chiefaiofficer-alpha.vercel.app)

---

## Tech Stack

- **Framework**: React 18 + TypeScript + Vite 5
- **Routing**: React Router DOM 6
- **Styling**: Tailwind CSS 3 + Vanilla CSS
- **Typography**: Inter (Body) & Poppins (Headings) via Google Fonts
- **Deployment**: Vercel

---

## Key Features

- **Interactive WhatsApp Simulator**: Interactive live chat demonstration showcasing multi-industry scenarios (Online Store, Clinic, Property, Personal Executive Assistant).
- **Mobile-First Responsive Design**: Tailored viewport heights, touch-friendly UI, and adaptive single-screen presentations.
- **Bilingual Support**: Instant toggle between Bahasa Indonesia (ID) and English (EN).
- **Production Optimized**: Fast loading bundle with zero runtime layout shift.

## Getting Started

### Prerequisites

- Node.js 18+
- npm or pnpm

### Installation

```bash
# 1. Clone repository
git clone https://github.com/lazverx/clevio-landing-page.git
cd clevio-landing-page

# 2. Install dependencies
npm install

# 3. Run development server
npm run dev
```

Open `http://localhost:5173` in your browser.

### Build & Preview

```bash
# Production build
npm run build

# Preview build output
npm run preview
```
